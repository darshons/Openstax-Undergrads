# Data contracts

The UI talks to two endpoints in `../BackEnd/api.py`:

- `POST /api/initial_script` — generates a script.
- `POST /api/modified_script` — saves user edits to a script.

This doc is the source of truth for the request/response shapes. Update it in
the same PR that changes any field.

---

## 1. Catalog — `CATALOG` (client-only)

The textbook library shown in the left rail is hand-curated in
`index.html`. It is not fetched from the backend; the backend takes
`{book_title, unit_num, chapter_num, page_num}` directly. The catalog only
exists to translate the user's section click into those four values.

```js
const CATALOG = [
  {
    id: "biology2e",            // unique slug, used in section IDs
    title: "Biology 2e",        // display name
    sub: "Clark · Douglas · Choi", // author line
    color: "#9ccb3b",           // spine accent (any CSS color)
    bookTitle: "Biology 2e",    // sent as backend `book_title` (must match ABL)
    chapters: [
      {
        n: "09",                // chapter number (string — keeps leading zeros)
        unit: 2,                // sent as backend `unit_num`
        name: "Cellular Respiration",
        secs: [
          { n: "9.1", t: "Energy in Living Systems" },
          { n: "9.2", t: "Glycolysis" },
        ],
      },
    ],
  },
];
```

### Section selection IDs
A selected section is tracked as a single string key:

```
`${book.id}:${chapter.n}:${section.n}`   // e.g. "biology2e:09:9.2"
```

`buildGenerateRequest({selected, model, userQuery})` uses the **first**
selected ID to fill `/api/initial_script` (only one section per call today).

## 2. Generate request — `POST /api/initial_script`

Pydantic model: `SceneInformation` in `BackEnd/api.py`.

```js
{
  book_title: "Biology 2e",      // must match an OpenStax ABL entry
  unit_num: 2,                   // required integer
  chapter_num: 9,                // optional integer
  page_num: "9.2",               // optional string (OpenStax-style page id)
  user_query: "A nursing student watches glucose metabolism…",
  model_choice: "anthropic"      // or "gemini"
}
```

Response:

```js
{
  message: "Initial script generation completed",
  script: { /* see §3 */ }
}
```

## 3. Script — what /api/initial_script returns and /api/modified_script accepts

The full branching script. Generated by the LLM from one of the JSON
templates in `BackEnd/Script_Generation_Pipeline/JSON_Templates/`.

```js
{
  title: "A Tour Inside the Mitochondrion",
  learning_goal: "…",
  target_audience: "Intro biology undergraduates",
  total_duration_seconds: 360,
  visual_style: "Clean 3D molecular animation…",

  characters: [
    {
      character_id: "A",                // short id used in scene.audio.dialogue[*].character_id
      name: "Maya",
      role: "Curious student narrator",
      appearance: {
        skin_tone: "warm beige",
        hair: "black, shoulder-length",
        build: "average",
        uniform: "hoodie + jeans",
        distinguishing_features: "silver hoop earrings",
      },
      emotional_baseline: "engaged, asks questions",
    },
  ],

  scenes: [
    {
      scene_id: 1,                      // 1-based, also the storyboard order
      type: "narrative",                // narrative | consequence | resolution
      scene_summary: "Hook: a sliced apple browning",
      duration_seconds: 20,
      setting: "Sunlit kitchen counter",
      character_actions: "Maya watches an apple slice slowly brown.",
      camera: {
        angle: "close-up",
        movement: "slow push-in",
        lens_effect: "shallow depth of field",
      },
      audio: {
        dialogue: [
          { character_id: "A", line: "Why does this happen so fast?" },
        ],
        sound_effects: "soft ambient kitchen",
        ambience: "morning light",
      },
      routes_to: {
        decision_point_id: 1,           // null if scene doesn't lead to a DP
        type: "introduction",           // introduction | true_choice | false_choice
      },
    },
  ],

  decision_points: [
    {
      decision_point_id: 1,
      question_text: "What does the cell do with pyruvate next?",
      associated_introduction_scene_id: 2,
      choices: [
        {
          choice_id: "A",
          text: "Feed it into the citric acid cycle",
          is_correct: true,
          misconception: null,           // string when is_correct === false
          routes_to_scene: 3,
        },
      ],
    },
  ],
}
```

### Field notes
- **`scene.type`** drives the colored card tag (`.scene-tag.narrative` etc.).
  Add a CSS rule alongside the existing five if you introduce a new type.
- **`scene.audio.dialogue[*].character_id`** is matched against
  `characters[*].character_id` — if the LLM emits an unknown id, the UI
  falls back to displaying the raw id.
- **`scene.routes_to.decision_point_id`** is `null` for scenes that don't
  branch.
- **`choice.is_correct`** is exclusive within a decision point — the UI's
  radio enforces this when editing.
- **`choice.routes_to_scene`** is the destination `scene_id` (not an index).

### Save request — `POST /api/modified_script`

```js
{ script: { /* the full object above, post-edit */ } }
```

Response: `{ message: "Final script generation request received" }`.
